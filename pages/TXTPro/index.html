TXTPro

简介

TXTPro 是一款开源的文本编辑器，旨在提供简洁、高效和个性化的写作体验。它支持所有文件格式，包括但不限于 TXT, HTML, Markdown 等，截止到2026/09/26的4.2.0版本，TXTPro 已经支持了全部类型的文件。

功能

  1. 支持所有格式
  2. 支持GBK(ANSI)、UTF-8(Unicode)编码的文件（不支持二进制文件）
  3. 辅助功能：
    • 字号
    • 字体
    • 光标位置：
      1. 行号
      2. 列号
  4. DeepSeek AI功能
  • TXTPro 的最新版本是4.2.0v，点击此处以查看更多信息。
