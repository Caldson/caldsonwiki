前言

起因是作者最近在学校研究货币，发现我们可恶的班级居然不让带星空纸，导致了主流的货币被砍断，还好我在2023年已经研究了一个叫做手册币的货币，但是它还是因为太古老、时代久远也摆脱不了它被抛弃的命运。

但是，有人可能就想问了：

  • UPUP，为怎么不用白纸？
  • 明明手册币那么好用，为什么不用了？

货币被砍断了

嗯......不得不说前面两个小伙伴们说的是对的，我们来逐步解决吧。

  1. 为什么不用白纸？

    白纸太容易携带，会严重导致货币贬值，从而引发混乱。

  2. 明明手册币那么好用，为什么不用了？

    我认为，手册币是用铅笔做的，容易伪造，也会严重导致货币贬值，从而引发混乱。

    因此，手册币已于2025年停用，XRing Studios Money Manager Center 将不再提供手册币。

解决方案

我们已于2026年10月16日推出了 Vitual XRing 货币，同时伴有可在第三方软件中登录。

例如，Decrive 音游支持登录 Vitual XRing。

对了，如果您也想使用 Vitual XRing 的API和SDK进行开发，您可以参照 Vitual XRing API 文档进行开发。

谢谢您对 Vitual XRing 的支持！
