怎么新增页面

页面放在 pages/<名称>/index.html，一个页面一个文件夹：

  1. 新建文件夹 pages/页面名/，在里面建 index.html，只写正文（标题用 <h1>，小节用 <h2>／<h3>，右侧目录自动生成）。
  2. 在 <head> 里声明这一页：{ "name": "页面名", "descript": "一句话简介" }，name 省略时用文件夹名。
  3. 在 </body> 前保留一行 <script src="../../dsh-ui.js"></script>（比根目录多两级 ../）。

根目录下的 *.html 同样会被收进来，两种结构可以混用。除此之外没有清单要维护：侧栏列表、这份索引和站内搜索都来自自动发现。

页面是怎么发现的

静态站点没法列出自己的目录，所以 dsh-ui.js 分三层自动发现，谁先给出结果就用谁：

  • 部署在 GitHub Pages 上时，直接问 GitHub API 要仓库根目录下的 .html 列表，第一次打开就是全的。
  • 如果仓库里放了可选的 pages.json 清单，就优先读它（格式见 README）。
  • 其它情况（例如本地双击打开）用 localStorage 自注册：每访问一个页面就登记一个，列表会越用越全。

快捷键

  • / 或 Ctrl+K：聚焦底部搜索框
  • ↑ ↓：在搜索结果里移动，Enter 打开
  • Esc：收起搜索结果，或关掉手机上的侧栏
